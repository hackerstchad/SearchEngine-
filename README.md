    149 +## Notes importantes
    150 +
    151 +- Un **moteur de recherche** possède ou interroge un index pour trouver de
         s pages.
    152 +- Un **métamoteur** regroupe les résultats de plusieurs moteurs.
    153 +- Les résultats, les règles de confidentialité et les pays couverts change
         nt avec le temps : consultez la politique de chaque service avant d'y effe
         ctuer des recherches sensibles.
    154 +- Les liens sont fournis à titre informatif et ne constituent pas une reco
         mmandation de sécurité ou de confidentialité.
